# ストア提出用ノート（note.com）下書き

公開前に note で2本（または1本にまとめて章分け）を公開し、
`www/index.html` 内の `STORE_LINKS` を実URLに差し替えてください。

## 1. プライバシーポリシー（必須）

含める項目の例:

- アプリ名「宝くじ生活」／運営者名（ハンドル可）
- 収集する情報
  - セーブは端末内 localStorage のみ。運営サーバーへは送らない
  - アプリ内課金の購入トークン / レシートは Apple または Google が処理する。コイン付与の重複防止 ID も端末内だけ
  - リワード広告では AdMob が広告 ID（IDFA / 広告 ID）を使う。同意（UMP、iOS は追跡の説明）のあとだけ広告を請求する
- 第三者: Apple、Google Play、Google AdMob（同意管理を含む）
- 問い合わせ先（メール or noteコメント）
- 改定日

## 2. 利用規約（必須に近い）

含める項目の例:

- 本アプリは娯楽用のシミュレーションであり、実在の宝くじ・抽選事業とは無関係
- ゲーム内通貨・当選金に換金性はない
- 年齢（例: 16歳以上推奨／ストアレーティングに合わせる）
- 禁止事項・免責・準拠法

## 3. サポート（任意だが推奨）

不具合報告・返金案内の窓口URLまたはメール。
